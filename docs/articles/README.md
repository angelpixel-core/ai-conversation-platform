# Artículos Técnicos

Un artículo por **vertical slice (User Story)**. Los refactors y cambios de arquitectura se documentan en ADRs (`.agent/architecture/decisions/`).

## Convenciones

* **Archivo:** `ARTICLE-<NNN>-<slug>.md` (ID secuencial de 3 dígitos; siguiente número libre).
* **Plantillas:** [`ARTICLE_TEMPLATE.python.md`](../../.agent/templates/ARTICLE_TEMPLATE.python.md) (proyecto) y [`ARTICLE_TEMPLATE.md`](../../.agent/templates/ARTICLE_TEMPLATE.md) (agnóstica).
* **Idioma:** español; identificadores de código en inglés.
* **Versionado:** en la feature branch, commit `docs(publication): add technical article for US-XX`.
* **Gate:** ver §4 de [`01-workflows-and-git.md`](../../.agent/rules/01-workflows-and-git.md).
* `Squash Commit en main: pendiente` es el único placeholder permitido hasta el merge.
